# Enhanced Playtrough

Welcome to _Enhanced playthrough_, An overhaul mod for Minecraft 1.20.1

---
## About the mod
- ### _Enhanced progress_
    Enhanced Playthrough (also mentioned as **_"EP2"_**) adds lots of features to vanilla Minecraft,
refactoring early and mid-game with new intermediate tiers and expanding late-game with side tiers that do not replace
**_Netherite_**, but instead co-exists with it and makes it a _situational tier_ (like the golden alloys!).
- ### _Enhanced difficulty_
    Now, the further you get on the game (counting days as progress), the harder it will become for you. New mobs and monsters are waiting for you,
my friend.
- ### _Enhanced nature_
    With the new construction materials, plants and crops, the overhaul experience of
the player is so extensible that seems like an endless _playthrough_.
- ### _Enhanced commerce_
    With the new gems added, the trade system has been rebalanced and you no longer can buy
diamond gear with simple emeralds, _you will need more valuable gems for that pal_.
---
## How to play
- To play _**Enhanced Playthrough**_, you will need the latest version of _Minecraft Forge_ for 1.20.1, that you'll find <a href= "https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html">here</a>
- Once Forge is installed, put the _.jar_ under the _/mods_ folder under _/.minecraft_, and you'll be ready to play _**Enhanced Playthrough**_.
  - If you have any doubt about the game loop, you can visit the <a href= "https://github.com/MarMar1134/Enhanced_Playtrough/wiki">Enhanced Playthrough wiki</a>.
