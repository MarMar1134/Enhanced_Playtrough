## Items
- Added _Purple gold ingot_. It can be made alloying gold with aluminum on a Blast alloy furnace.
  - Also added Purple gold _nuggets_ and _dust_.
  - Like other gold types, Purple gold can distract Piglins and be used on a Beacon as a payment.
- Added _Purple gold rod_: this new item can be used to craft tools with a _Purple golden handle_, a new _Handle tier_ which increases destroy speed at the cost of some durability.

---

## Blocks
- Added _Block of purple gold_. It can be used as a base for the _Beacon_ and de-crafted onto 9 _Purple gold ingots_
- Added _Mud bricks alloy furnace_: This new alloy furnace acts as an intermediate step between the vanilla _furnace_ and the _bricks alloy furnace_ being on the
  same level as the _mud furnace_.
  - The _mud bricks alloy furnace_ is crafted using 5 _mud bricks_ blocks and 3 _cobble type_ blocks. 
  - The _mud bricks alloy furnace_ can only make _brass_ and _bronze_, as it doesn't produce enough heat to forge _steel_.

## World gen
- **_Copper ores_** are now generated on two different layers:
  - The first layer generates between Y=-16 to Y=104, using the `triangle` configuration. This layer tries to generate a max of 12 clusters with a max size of 12 ores per cluster.
  - The second layer generates between Y=-64 to Y=12, using the `uniform` configuration. This layer tries to generate a max of 10 clusters with a max size of 8 ores per cluster.
  - There is a bonus generation for `mountain` biomes that tries to add a max of 10 clusters with a max size of 12 ores per cluster. This layer generates between Y=10 to Y=320.
  - There is a bonus generation for `dripstone caves` biomes that tries to add a max of 6 clusters with a max size of 12 ores per cluster. This layer generates between Y=-16 to Y=104.
- **_Iron ores_** are now generated on three different layers:
  - The first layer generates between Y=60 to Y=320, using the `triangle` configuration. This layer tries to generate a max of 5 clusters with a max size of 7 ores per cluster.
  - The second layer generates between Y=12 to Y=70, using the `triangle` configuration. This layer tries to generate a max of 8 clusters with a max of 5 ores per cluster.
  - The third layer generates between Y=-64 to Y=12, using the `uniform` configuration. This layer tries to generate a max of 10 clusters with a max size of 7 ores per cluster. 
  - There is a bonus generation for `mountain` biomes that tries to add a max of 10 clusters with a max of 8 ores per cluster. This layer generates between Y=24 to Y=320.
- **_Diamond ores_** are now generated on two different layers:
  - The first layer (the _legacy_ layer) generates between Y=0 to Y=24, using the `triangle` configuration. This layer tries to generate a max of 5 clusters with a max size of 3 ores per cluster.
  - The second layer (the _modern_ layer) generates between Y=-80 to Y=12, using the `triangle` configuration. This layer tries to generate a max of 7 clusters with a max size of 5 ores per cluster.
  - There is a bonus generation for `savanna` biomes that tries to add a max of 4 clusters with a max size of 3 ores per cluster. This layer generates between Y=-80 to Y=80.

## Handle tiers
- Added new Handle tier: _Purple gold_ is more advanced than _Reinforced_ being at the same level as _Aluminum_.
- Tools with a _Purple golden handle_ have 20% less durability, but a huge boost on its mining speed.
  - This bonus has a base of +2 and is incremented based on the tool's _Efficiency level_ using the given formula: 'handleTier * EfficiencyLevel'.
  - If the Efficiency level were equal or less than 0, only the base _Handle bonus_ would be applied.
- _Purple gold handles_ also adds some _attack speed_ to all the tools.
