## Beta 0.27.0.0: alloy update
- Rework _bronze_ and _steel_ alloys to get a better game progression. This could involve change the _alloy furnace_ recipes.
- Add new alloys and new tool handles, with modifies different properties of the tools.
  - One of these alloys could be _purple gold_ which is gold and aluminum.
- Make iron a required step to get steel.
  - This could be achieved creating a distinction between _rich coal_ and _poor coal_. The first one is mined with iron tools, meanwhile the second one is the vanilla _coal_.

## Beta 0.28.0.0: wooden update
- Add new tool: the saw. Is used on wood-working.
- Rework the start of the game, making _logs_ drop an item instead of the full block.
  - With these logs, the player must craft a _saw_ and combine it to get _planks_.
  - Like minerals, _iron tools_ allows the player to get the log block instead of the item.
- Add new enchantments to the axes allowing the player to still get log items from the logs or get the planks, similar to _fine mining_ and _rough mining_.
- Add a _sawmill_. It works like the _stone-cutter_ but for wooden blocks.
- Add a _wood transmutator_, late-game block that allows the player to get any log using a catalyst.
  - For example, the player could get _acacia_ logs transmutating _birch_ or _jungle_ logs.
